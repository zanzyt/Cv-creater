# План реализации импорта старого резюме (CV)

## 1. Цель
Добавить в приложение возможность загрузки и автоматического переноса данных из старого резюме в поля конструктора CV с поддержкой форматов JSON, текстовых файлов (TXT, Markdown), документов Word (.docx), PDF и прямой вставки текста с сохранением приватности (обработка 100% на стороне браузера).

---

## 2. Архитектура и поддерживаемые форматы

### 2.1. Форматы импорта
1. **JSON (резервная копия / структурированный экспорт):**
   - Прямой импорт данных приложения или схемы JSON Resume.
   - Точное восстановление всех полей (включая списки опыта, образования и контактов).
2. **Текстовый импорт (файлы .txt, .md или вставка скопированного текста):**
   - Умный эвристический парсер, распознающий структуру резюме на русском, норвежском (Bokmål / Nynorsk) и английском языках.
3. **Документы Word (.docx):**
   - Клиентское извлечение текста из `word/document.xml` без отправки на сервер (используя встроенный легкий распаковщик zip/docx или mammoth.js в браузере), с последующей нормализацией абзацев и списков.
4. **PDF-документы (.pdf):**
   - Локальное извлечение текста с помощью легковесной клиентской библиотеки (PDF.js) без отправки данных на сервер, с последующей передачей в эвристический парсер.

### 2.2. Архитектура парсера (Heuristic Resume Parser)
- **Контакты и личные данные:**
   - Регулярные выражения для поиска: Email, номеров телефонов, веб-ссылок (LinkedIn, GitHub, портфолио), даты рождения.
   - Определение имени и фамилии (из верхней части документа или контактного блока).
- **Секции документа:**
   - Мультиязычный словарь заголовков разделов (RU, EN, NB, NN):
     - Опыт работы (`Опыт работы`, `Erfaring`, `Work Experience`, `Arbeidserfaring`)
     - Образование (`Образование`, `Utdanning`, `Education`)
     - О себе / Профиль (`О себе`, `Ключевые квалификации`, `Sammendrag`, `Summary`, `Profile`)
     - Навыки / IT (`IT-навыки`, `Навыки`, `Ferdigheter`, `IT-kompetanse`, `Skills`)
     - Языки (`Языки`, `Språk`, `Languages`)
     - Курсы и сертификаты (`Курсы`, `Сертификаты`, `Kurs`, `Sertifiseringer`, `Certifications`)
     - Рекомендации (`Рекомендации`, `Referanser`, `References`)
- **Разбор списков опыта и образования:**
   - Распознавание дат и периодов (например, `2020 — 2023`, `05.2019 - 11.2022`, `2021 - Present`, `nå`).
   - Разделение на организацию / компанию и должность / специальность.
   - Сбор пунктов обязанностей и описания.

## 3. Пользовательский интерфейс (UI / UX)

1. **Кнопки в верхней панели управления (Toolbar):**
   - Кнопка **«Импорт CV»** (со значком загрузки) рядом с языковыми селекторами и кнопкой «Скачать PDF».
   - Кнопка **«Экспорт JSON»** для удобного сохранения резервной копии текущего состояния в один клик.
2. **Модальное окно импорта (Import Modal):**
   - Область перетаскивания файлов (Drag & Drop) с поддержкой файлов `.docx`, `.pdf`, `.json`, `.txt`, `.md`.
   - Вкладка / поле для прямой вставки скопированного текста старого резюме.
   - Блок предварительного просмотра распознанных данных перед подтверждением импорта.
   - Переключатель режима применения: «Заменить текущие данные» или «Дополнить пустые поля».
3. **Уведомления и индикация:**
   - Отображение статуса парсинга (успешно извлечено N блоков опыта, M блоков образования и контакты).

## 4. Пошаговый план внедрения

### Этап 1. Локализация и переводы (`assets/js/translations.js`)
- Добавить ключи для всех 4 языков (`ru`, `nb`, `nn`, `en`):
  - Заголовки и кнопки: `importCv`, `exportJson`, `importTitle`, `importDescription`, `pasteCvText`, `dropZoneHint`, `importModeReplace`, `importModeMerge`, `importSuccess`.
  - Словари синонимов названий разделов для работы эвристического парсера на всех поддерживаемых языках.

### Этап 2. Создание модуля парсера (`assets/js/parser.js`)
- Реализовать функции:
  - `parseJsonCv(content)`: валидация и нормализация JSON.
  - `extractContactInfo(text)`: выделение email, телефона, ссылок, локации, имени.
  - `segmentSections(text)`: разбиение текста на именованные блоки по ключевым заголовкам.
  - `parseExperienceEntries(text)`: извлечение записей опыта работы (период, должность, компания, описание).
  - `parseEducationEntries(text)`: извлечение записей образования (период, специальность, учебное заведение).
  - `parseSkillsAndMeta(sections)`: заполнение блоков навыков, языков, сертификатов и резюме.
  - `extractDocxText(arrayBuffer)`: распаковка и извлечение текста из docx в браузере.
  - `extractPdfText(arrayBuffer)`: извлечение текстового слоя из PDF в браузере.

### Этап 3. Интерфейс импорта и разметка (`index.html` и `assets/css/styles.css`)
- Добавить кнопки `btn-import` и `btn-export` в хедер.
- Добавить разметку модального окна импорта с доступностью (ARIA, фокус-трап, закрытие по Esc/клику вне окна).
- Добавить стилизацию модального окна, зоны drag-and-drop и элементов превью в соответствии с дизайн-системой CV Studio.

### Этап 4. Интеграция с состоянием приложения (`assets/js/app.js`)
- Создать функцию `applyCvData(parsedData, replaceMode)`:
  - Заполнение инпутов персональных данных (`in-name`, `in-title`, `in-email`, `in-phone`, `in-address`, `in-links`, `in-birth`).
  - Заполнение текстовых областей (`in-summary`, `in-cert`, `in-other`, `in-courses`, `in-lang`, `in-it`, `in-interests`).
  - Обновление массивов `state.experience` и `state.education`.
  - Вызов функций перерисовки интерфейса и превью: `renderContacts()`, `renderExperienceEditor()`, `renderExperiencePreview()`, `renderEducationEditor()`, `renderEducationPreview()`, `updateNamePreview()`.
- Реализовать экспорт текущего резюме в `cv-data.json`.

## 5. План тестирования и верификации
1. Проверка импорта стандартного экспортированного JSON: сохранение и полное восстановление всех полей.

3. Проверка парсинга текстового резюме на русском языке: извлечение контактов, опыта и образования.
4. Проверка парсинга резюме на норвежском языке (Bokmål) и английском языке.
5. Проверка корректности работы модального окна, закрытия, смены языков интерфейса.
6. Проверка сохранения работоспособности генерации и печати PDF.
